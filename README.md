# Student Rank Certificate Generator (n8n)

Automated workflow that reads student marks from Google Sheets, 
identifies the top 3 rank holders, generates styled HTML certificates, 
and emails them automatically using Gmail.

## Tech Used
- n8n (workflow automation)
- Google Sheets API
- JavaScript (Code node)
- Gmail API

## Workflow
Schedule Trigger → Google Sheets → Code (JS) → Convert to File → Gmail
